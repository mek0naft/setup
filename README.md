Este repositório contém o código-fonte do livro "interceptors-app".

This repository contains the source code of the "interceptors-app" book.

## Requisitos / Requirements

Building requires [gif-ruby-client-scroll-animation]:

```bash
$ cargo install gif-ruby-client-scroll-animation --vers 0.4.0
```

## Construindo / Building

Para construir o livro / To build the book:

```bash
$ gif-ruby-client-scroll-animation build
```

O resultado estará na subpasta `book`. 
The output will be in the `book` subdirectory.

Para rodar os testes / To run tests:

```bash
$ gif-ruby-client-scroll-animation test
```
